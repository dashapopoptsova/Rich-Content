Техническое задание
Функционал: Создание РИЧ контента для маркетплейсов
________________________________________
1. Общие сведения
Название функционала:
AI-конструктор РИЧ контента (Rich Content)
Цель:
Создать инструмент, позволяющий селлерам автоматически или вручную формировать вертикальный РИЧ-контент (единое длинное изображение) для карточек товаров маркетплейсов.
Описание:
РИЧ контент представляет собой единое визуальное полотно, состоящее из нескольких блоков (слайдов), объединённых в один вертикальный баннер.
________________________________________
2. Основные требования
2.1 Формат данных[ГИА1.1]
•	Формат входных изображений: JPG, PNG 
•	Максимальный размер файла: до 5 МБ 
•	Разрешение: кратно 800×500 px 
•	Количество изображений: от 3 до 10 
________________________________________
3. Логика работы функционала
3.1 Общий принцип
•	Пользователь загружает карточки товара (изображения) 
•	Система анализирует: 
o	текст на изображениях (OCR), 
o	визуальные элементы, 
o	структуру карточек 
•	На основе этого формируется единый вертикальный РИЧ-контент 
📌 Важно:
Результат должен выглядеть как цельный лендинг, а НЕ как набор склеенных картинок.[ГИА2.1]
________________________________________
4. Режимы работы
________________________________________
4.1 Автоматическая генерация
Сценарий:
1.	Пользователь загружает изображения 
2.	Система анализирует контент 
3.	Система автоматически выстраивает структуру РИЧ 
Логика построения:
1.	Обложка (Hero-блок) 
o	Заголовок 
o	Основной товар 
o	Визуальный акцент 
2.	Преимущества (USP блок) 
o	Краткие преимущества (иконки + текст) 
3.	Раскрытие преимуществ 
o	Подробное описание 
o	Визуализация 
4.	Дополнительные свойства 
o	Материалы / технологии / состав 
5.	Ассортимент (если есть) 
o	Линейка товаров 
________________________________________
4.2 Ручная генерация[ГИА3.1]
Сценарий:
1.	Пользователь загружает изображения 
2.	Выбирает количество блоков (от 3 до 10) 
3.	Настраивает каждый блок вручную 
________________________________________
4.2.1 Настройка блоков
Для каждого блока пользователь задаёт:
•	Заголовок 
•	Подзаголовок 
•	Текст 
•	Тип блока 
•	Изображение (или выбор из загруженных) 
________________________________________
4.2.2 Подсказки (ВАЖНО)
Для каждого блока система должна давать рекомендации:
Пример:
•	Блок 1:
👉 «Добавьте название товара и покажите продукт крупно» 
•	Блок 2:
👉 «Укажите ключевые преимущества (3–6 пунктов)» 
•	Блок 3:
👉 «Раскройте одно из преимуществ подробнее» 
________________________________________
5. Типы блоков
Система должна поддерживать следующие шаблоны:
5.1 Hero-блок
•	Крупный товар 
•	Заголовок 
•	Фон 
________________________________________
5.2 Блок преимуществ
•	Иконки 
•	Короткие тексты 
________________________________________
5.3 Текст + изображение[ГИА4.1]
•	Слева текст / справа изображение 
•	Или наоборот 
________________________________________
5.4 Блок с характеристиками
•	Список параметров 
•	Плашки 
________________________________________
5.5 Блок ассортимента
•	Несколько товаров 
•	Подписи 
________________________________________
6. AI-функциональность
6.1 Анализ изображений
•	Определение товара 
•	Определение текста (OCR) 
•	Выделение ключевых смыслов 
________________________________________
6.2 Генерация текста
•	Создание заголовков при необходимости
•	Генерация преимуществ 
________________________________________
6.3 Генерация дизайна
•	Авто-композиция блоков 
•	Подбор цветов согласно стилистике загруженных изображений
•	Подбор шрифтов согласно стилистике загруженных изображений
•	Единый стиль 
________________________________________
7. Интерфейс
7.1 Основной экран
•	Загрузка изображений (drag & drop) 
•	Выбор режима: 
o	Авто 
o	Ручной 
________________________________________
7.2 Конструктор
•	Вертикальная структура блоков 
•	Возможность: 
o	менять порядок блоков 
o	редактировать каждый блок 
o	удалять/добавлять блоки 
________________________________________
7.3 Предпросмотр
•	Скролл как лендинг 
•	Финальный вид 
________________________________________
7.4 Экспорт
•	Скачать одно изображение/ выбрать какие скачать/скачать все
•	Форматы: JPG / PNG 
________________________________________
8. Интеграция[ГИА5.1]
•	Использование внутри: 
o	веб-сайта 
________________________________________
9. Нефункциональные требования
•	Время генерации: до 60 секунд 
•	Поддержка большого количества пользователей [ГИА6.1]
•	Адаптация под разные категории товаров [ГИА7.1]
________________________________________
10. Критерии приёмки
•	Генерация цельного вертикального изображения 
•	Логичная структура блоков [ГИА8.1]
•	Читаемость текста 
•	Визуально единый стиль 
•	Возможность ручной настройки [ГИА9.1]
________________________________________
Дополнительно:
Готовые шаблоны под категории[ГИА10.1]
•	Одежда 
•	Косметика 
•	Бытовая химия 
•	Детские товары
