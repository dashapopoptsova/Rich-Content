# Техническое задание: AI-конструктор РИЧ контента (Rich Content)

**Функционал:** создание РИЧ контента для маркетплейсов.

---

## Цель проекта

Создать инструмент, позволяющий селлерам **автоматически или вручную** формировать **вертикальный РИЧ-контент** — единое длинное изображение для карточек товаров на маркетплейсах.

**Описание продукта:** РИЧ контент — это единое визуальное полотно из нескольких блоков (слайдов), объединённых в один вертикальный баннер.

**Ключевой принцип качества:** итог должен выглядеть как **цельный лендинг**, а не как набор склеенных картинок.

---

## Стек технологий

В исходном ТЗ **конкретные языки, фреймворки и облака не зафиксированы**. Из требований следуют следующие **технические области и ограничения**:

| Область | Требования из ТЗ |
|--------|-------------------|
| **Клиент / встраивание** | Веб-интерфейс; использование **внутри веб-сайта** (интеграция). |
| **Работа с изображениями** | Загрузка JPG/PNG, drag & drop; экспорт **одного или нескольких** изображений (JPG/PNG); сборка вертикального полотна из блоков. |
| **ИИ / анализ** | OCR (текст на изображениях); анализ визуальных элементов и структуры карточек; определение товара; выделение ключевых смыслов; генерация заголовков и преимуществ; автокомпозиция и подбор цветов/шрифтов под стиль загрузок. |
| **Производительность и масштаб** | Генерация за **до 60 секунд**; **поддержка большого числа пользователей** (см. нефункциональные требования). |

Выбор конкретного стека (SPA-фреймворк, бэкенд, модели OCR/LLM, хранение файлов) — на этапе проектирования с учётом интеграции и нагрузки.

## Функциональные требования

### Формат входных данных

- Форматы изображений: **JPG, PNG**.
- Максимальный размер файла: **до 5 МБ**.
- Разрешение: **кратно 800×500 px**.
- Количество изображений: **от 3 до 10**.

### Общая логика

1. Пользователь загружает карточки товара (изображения).
2. Система анализирует: текст на изображениях (OCR), визуальные элементы, структуру карточек.
3. На основе анализа формируется единый вертикальный РИЧ-контент.

### Режимы работы

**Автоматическая генерация**

1. Загрузка изображений → анализ контента → автоматическое выстраивание структуры РИЧ.

**Целевая логика построения (авто):**

1. Обложка (Hero): заголовок, основной товар, визуальный акцент.
2. Преимущества (USP): краткие преимущества (иконки + текст).
3. Раскрытие преимуществ: подробное описание, визуализация.
4. Дополнительные свойства: материалы / технологии / состав.
5. Ассортимент (при наличии): линейка товаров.

**Ручная генерация**

1. Загрузка изображений.
2. Выбор количества блоков (**от 3 до 10**).
3. Ручная настройка каждого блока.

**Настройка блока (ручной режим):** заголовок, подзаголовок, текст, тип блока, изображение (или выбор из загруженных).

**Подсказки по блокам:** для каждого блока система выдаёт рекомендации (пример из ТЗ: «Добавьте название товара…», «Укажите ключевые преимущества (3–6 пунктов)», «Раскройте одно из преимуществ подробнее» и т.д.).

### Типы блоков (шаблоны)

| Тип | Содержание |
|-----|------------|
| **Hero-блок** | Крупный товар, заголовок, фон |
| **Блок преимуществ** | Иконки, короткие тексты |
| **Текст + изображение** | Текст слева / изображение справа или наоборот |
| **Характеристики** | Список параметров, плашки |
| **Ассортимент** | Несколько товаров, подписи |

### AI-функциональность

- **Анализ изображений:** определение товара, OCR, выделение ключевых смыслов.
- **Генерация текста:** заголовки при необходимости, формулировка преимуществ.
- **Генерация дизайна:** автокомпозиция блоков; подбор цветов и шрифтов по стилистике загруженных изображений; единый стиль.

### Интерфейс

- **Основной экран:** загрузка изображений (drag & drop); выбор режима «Авто» / «Ручной».
- **Конструктор:** вертикальная структура блоков; смена порядка; редактирование блоков; удаление и добавление блоков.
- **Предпросмотр:** скролл как у лендинга; финальный вид.
- **Экспорт:** скачать одно изображение / выбрать какие скачать / скачать все; форматы **JPG / PNG**.

### Интеграция

- Использование **внутри веб-сайта**.

### Дополнительно (из ТЗ)

- **Готовые шаблоны под категории:** одежда; косметика; бытовая химия; детские товары.

### Критерии приёмки (функциональные ожидания)

- Генерация **цельного** вертикального изображения.
- **Логичная** структура блоков.
- **Читаемость** текста.
- **Визуально единый** стиль.
- Возможность **ручной** настройки.
